# AVAC4QGIS 0.6.1 - Windows

This is the numerical checkpoint accepted for publication on 2026-09-06.
It promotes the existing tested Windows solver binaries without changing
physical parameters or defaults. Packaging adds the missing third-party licence
texts and updates the installation documentation. Earlier investigation documents describe
their historical checkpoints; their release holds are superseded by this
publication decision, not by a claim that every numerical limitation is solved.

## Installation

Download `avac_qgis-0.6.1-windows-amd64.zip` from the
[v0.6.1 release](https://github.com/cgotelli/AVAC-QGIS/releases/tag/v0.6.1),
then use **Plugins > Manage and Install Plugins > Install from ZIP** in QGIS.
Supports Windows AMD64 and QGIS 3.40 or newer; the packaged workflow was tested
with QGIS 3.40.11-Bratislava. AVAC, WAVE, Clawpack, and required native libraries
are bundled: users do not install a compiler or a separate solver environment.
This release does not supply an updated macOS binary.

## Included changes

- Terrain-tangent momentum transport and consistent terrain/input precision.
- General shallow-flow correction-flux and static-interface balance changes.
- Source-aware timestep control and CFL rejection/retry handling.
- Correct Voellmy and cohesive-Voellmy stopping: an exact zero from the friction
  update is no longer replaced by incoming momentum.
- Matching plugin preparation, runtime support, and regression tests.

The existing rheology-specific defaults are unchanged: Coulomb uses Minmod,
CFL 0.25 and regularization depth 0.05 m; Voellmy uses Van Leer, CFL 0.5 and
regularization depth 0.1 m. The later Voellmy CFL 0.25 sensitivity run remains
an experiment, not a new default.

## Validation scope and limitations

The final ZIP passed release-integrity validation. Before the licence-only
runtime repack, the same plugin execution code and native binaries passed an
isolated QGIS workflow that automatically installed both managed runtimes and
completed a native Voellmy run. The offscreen QGIS process subsequently crashed at shutdown;
the functional workflow passed, but this is not a clean-exit certification.

The recorded broad suite had 589 passes, 5 skips and one source-acceptance hash
failure (and one deselected test). That hash checkpoint is explicitly updated
for this accepted release; its three focused tests pass. The broad suite was
not rerun for this pin-only edit, and the new pin is not evidence of numerical
equivalence to the earlier checkpoint. The packaging and runtime-installation
suite additionally passed all 46 tests before the licence packaging changes;
50 packaging checks passed after the update.
Compiled source-stopping regressions passed. The immediate pre/post stopping-fix
flat Coulomb and water controls were unchanged (Kerswell differed only at
roundoff), while earlier static-interface changes did alter some flat states.
Full ISeeSnow runs and peer-comparison figures are retained in the validation
evidence archive. Near-dry velocity sensitivity and mixed timestep-refinement
effects remain documented; no universal temporal-convergence claim is made.
