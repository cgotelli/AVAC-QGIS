# AVAC4QGIS 1.0.0 — Linux x86_64

`avac_qgis-1.0.0-linux-x86_64.zip` is the installable QGIS package for Linux
x86_64. Install it through **Plugins > Manage and Install Plugins > Install
from ZIP**, then restart QGIS.

The package was built and tested with QGIS 3.40.15-Bratislava on Ubuntu 26.04.
It requires QGIS 3.40 or newer and glibc 2.43 or newer. It contains AVAC and
WAVE executables, Clawpack 5.14.0 source used by the data writers, GNU Fortran
and OpenMP runtime libraries, and all numerical libraries required by the
solvers. End users do not need to install a compiler, Clawpack, BLAS, LAPACK,
or any other solver dependency manually.

The package does not bundle glibc itself; Linux distributions provide it as a
core operating-system component. The release manifest records the glibc floor
from the ELF symbol requirements of the solver and bundled shared libraries.
