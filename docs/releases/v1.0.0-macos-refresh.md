# AVAC4QGIS 1.0.0 — replacement macOS release

This release replaces the earlier `v1.0.0` publication with the tested macOS
candidate, current source on `main`, and current methods manuscript. The
replacement `v1.0.0` source tag is moved to the release commit so GitHub's
source archives include these changes and the complete `docs` directory.
Earlier numbered releases are retained.

## Packages and installation

- **macOS:** `avac_qgis-1.0.0-macos-arm64.zip`, for Apple Silicon, **macOS
  26.0 or newer**, and QGIS 3.40 or newer; tested with QGIS 3.44 LTS.
- **Windows:** `avac_qgis-1.0.0-windows-amd64.zip` is retained byte-for-byte
  from the original Windows release. It has not been rebuilt with the later
  macOS preparation/performance changes. Its original manifest and
  [Windows release notes](v1.0.0-windows.md) remain the provenance record.
- No Linux or Intel Mac binary is attached to this release.

Install the appropriate ZIP through **Plugins > Manage and Install Plugins >
Install from ZIP**, then restart QGIS. Existing 1.0.0 and local candidate
installations must be explicitly replaced; the unchanged public version
number does not trigger an automatic update. Prepare a new WAVE run to use
the new runtime selection; a completed AVAC result can be reused.

The macOS plugin is marked stable (`experimental=False`). It bundles the
exact tested AVAC `1.0.1-rc3` and WAVE `1.0.1-rc5` runtime archives. These
are internal cache identities, independent of the public plugin version;
retaining them preserves the tested bytes and prevents reuse of old 1.0.0
runtimes. No solver was recompiled merely to change the release label.

## Changes and verification

The macOS package includes faster input preparation, inward domain fitting
for AVAC and WAVE, bounded fixed-grid output work, improved patch scheduling,
exact empty-patch and stationary-source shortcuts, reusable private CFL
buffers, and the exact WAVE speed-only CFL preflight. It does not relax CFL
limits, change physical equations, reduce output precision, or introduce a
new approximate wet/dry exclusion rule. Accepted steps retain the full
Riemann update.

The final candidate passed 1,016 validation regression tests, 178 source
plugin tests, and 73 packaged checks. Native AVAC retry checks passed
separately. WAVE comparisons covered shorelines, two-level AMR, rejected CFL
trials, and one/four-thread reproducibility. Six bounded Trift runs produced
identical solution, auxiliary, fixed-grid output, and CFL sequences; median
complete-process time decreased by about 6%. This is a short performance
measurement, not a guaranteed full-run speedup or a new scientific validation.

The historical candidate notes
([rc1](v1.0.1-rc1-macos.md), [rc2](v1.0.1-rc2-macos.md),
[rc3](v1.0.1-rc3-macos.md), [rc4](v1.0.1-rc4-macos.md),
[rc5](v1.0.1-rc5-macos.md)) document the individual changes and limitations.
Their statements about unpublished builds describe those test stages, not
the status of this replacement release. Existing output storage requirements
remain unchanged.

## Article and provenance

The release includes the current `AVAC4QGIS_GMD.pdf` and an editable article
source ZIP. The repository also contains the LaTeX source, bibliography,
figures, tutorial, and interface reference. The article remains a working
methods manuscript; its archived ISeeSnow and other scientific figures are
not relabeled as new simulation runs. Original Windows executable hashes
in the manuscript still refer to the unchanged Windows binaries.

The macOS release manifest records the promoted archive and executable
hashes, while the release body records the exact source commit. The existing
`solver_source_sha256` field is the pre-relocation executable hash, not a
source-tree hash. The previous v1.0.0 assets and metadata were backed up
locally before replacement.

Promotion checks passed: 63 focused packaging tests, full nested-runtime
release validation, and 73 staged-plugin checks plus a native WAVE grid-fit
run. The stable ZIP matches the tested rc5 ZIP byte-for-byte in every file
except the updated README and stable plugin metadata.
