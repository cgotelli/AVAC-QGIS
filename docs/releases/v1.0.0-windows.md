# AVAC4QGIS 1.0.0 - Windows

Version 1.0.0 promotes the accepted 0.6.1 numerical checkpoint to `main` and
adds the updated methods manuscript, editable LaTeX source, bibliography and
current ISeeSnow peer-comparison figure. It does not retune the solver or
rerun the scientific cases merely to change the version number.

## Installation

Download `avac_qgis-1.0.0-windows-amd64.zip` from the
[1.0.0 release](https://github.com/cgotelli/AVAC-QGIS/releases/tag/v1.0.0),
then select **Plugins > Manage and Install Plugins > Install from ZIP** in QGIS.
Supports Windows AMD64 and QGIS 3.40 or newer. Both AVAC and WAVE runtimes,
Clawpack 5.14.0, native libraries and component licences are bundled; users
do not need a compiler or a separately installed solver environment.
This release does not include new macOS or Linux binaries.

## Documentation and numerical scope

The [methods manuscript](../article/AVAC4QGIS_GMD.pdf) now describes the
implemented terrain-tangent transport, distinct Voellmy/Coulomb stopping
handling, conservative shallow-layer correction-flux damping, positivity
relimiting, actual-head static-yield guard, terrain precision, and incoming-state
CFL preflight with synchronized AMR retry. It distinguishes these mechanisms
from a full post-source stability or convergence guarantee.

The current ISeeSnow scalar figure is replotted from authenticated completed
runs using the exact released AVAC executable. Historical flat/water/coupling
figures are labelled at their own checkpoints, not presented as new 1.0.0
simulation runs. Observational and coupled laboratory validation sections
remain explicitly unfinished in the working manuscript.

The code's controls are unchanged. For clarity, the plugin's model-selection
default is Minmod for Coulomb and Superbee for both Voellmy laws; its global
CFL defaults are target 0.5 and ceiling 1.0. The recorded ISeeSnow protocol
explicitly uses Minmod/CFL 0.25 for Coulomb and Van Leer/CFL 0.5 for Voellmy.
The earlier 0.6.1 release description conflated those benchmark settings with
general plugin defaults; this is a documentation correction, not a change
to saved-case settings or production behaviour.

## Verification of this release

- All versioned runtime payload files retain their 0.6.1 bytes; only each
  runtime manifest's version label changes.
- Full release validation passes, along with 64 packaging/runtime tests and
  actual isolated AVAC/WAVE installation and corruption-repair checks.
- The previous QGIS 3.40.11-Bratislava functional workflow exercised the same
  production code and binaries. Its offscreen process crashed afterward at
  shutdown; it is not claimed as a clean-exit test or a new 1.0.0 GUI run.
- Near-dry/timestep sensitivity and the limited scope of earlier flat/AMR
  preservation checks remain documented. A release number is not a new
  scientific validation claim.
