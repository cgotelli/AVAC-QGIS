# Local macOS performance test build

This is a local Apple Silicon test package, not a published release. The AVAC
runtime has the separate identity `1.0.1-rc1`, so testing it does not overwrite
the installed `1.0.0` runtime. The bundled WAVE runtime remains `1.0.0`.

## Changes

- FGout interpolation visits only output cells near the current computational
  patch, retaining the original coordinate test and interpolation order.
- FGmax checks whether terrain sampling is complete once after each level's
  patch workers finish, and stops checking completed levels. Previously it
  scanned the entire fixed grid after every patch, even after completion.
- Flux and CFL calculations skip patches only when every state component,
  including all ghost cells, is exactly zero. Wet neighboring cells, shallow
  films, and residual momentum retain the full calculation. Source updates,
  observations, and patch clocks are not skipped.
- Single-level AVAC runs use a maximum patch side of 250 cells, including ghost
  cells, instead of 60. This changes domain partitioning, not mesh resolution.
  Runs with multiple refinement levels retain the previous limit.

The equations, numerical precision, CFL limits, output times, and peak-check
frequency are unchanged.

## Trift timing check

The existing Trift inputs were copied into isolated temporary runs. Each run
covered the first simulated second on the same 2 m mesh (5,247,902 cells), used
eight threads, and accepted the same 15 time steps.

| Solver | Patch limit | Number of patches | Wall time through first simulated second |
| --- | ---: | ---: | ---: |
| Previous binary | 60 | 4,096 | 78.37 s |
| Previous binary | 250 | 128 | 11.83 s |
| Optimized binary | 60 | 4,096 | 7.15 s |
| Optimized binary | 250 | 128 | 6.49 s |
| Installed test-package binary | 250 | 128 | 6.54 s |

These are single-run measurements from `timing.csv`, not whole-avalanche
completion estimates. Total process time, including input loading and final
peak-file writing, was 93.84 s before and 21.11 s after the combined changes.
Later speed depends on flow extent and the CFL-limited time step; writing the
large output grids still takes time.

The final ZIP was also installed into an isolated temporary runtime cache and
rerun on the same inputs. Its total process time was 23.08 s; its solution,
FGout, and FGmax files were byte-identical to the previous 250-cell-patch run.

For matching patch layouts, the initial/final solution binaries, FGout frames,
and FGmax files were byte-identical between the previous and optimized solvers.
FGout and FGmax files were also byte-identical across the two patch layouts.
Compiled regression tests cover interpolation boundaries, FGmax completion,
and dry-patch equivalence with the original numerical kernels.
The numerical suite passed 589 checks; its additional opt-in native CFL test
also passed, confirming byte-identical output across one and four threads and
across rejected-trial versus direct accepted-time-step runs on two AMR levels.
Plugin checks passed in both the source (100 tests) and staged macOS package
(22 runtime-dependent tests). The package passed release integrity validation.

## Testing in QGIS

Install the local `avac_qgis-1.0.1-rc1-macos-arm64.zip` using **Install from ZIP**,
then restart QGIS. Prepare a new AVAC run from the existing case settings: an
already prepared run retains its old patch limit in `amr.data`. Keep the mesh,
physical parameters, and output settings unchanged for comparison. The
original Trift run and the published release are not modified by this check.
